Immich ranks your whole library by likeness without end, so a text search includes many non-matches. "Best of" double-checks each result against your own enrichment data (AI tags/captions), stops where confirmed matches run out, and ranks the keepers by your Curate decisions and photo scores — so a Top 50 album is your best 50, not the first 50.

  • Only enriched photos can be confirmed
  • Without Best of, a Result Size limit is recommended: Immich does not return a bounded set
